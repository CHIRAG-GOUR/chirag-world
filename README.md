# Chirag Gour — The City

An explorable 3D city portfolio. Start at Chirag's desk, step outside, take the car, and explore districts built from his real work.

**Stack:** Next.js 16 · React 19 · React Three Fiber · Three.js · Rapier physics · @react-three/postprocessing · Zustand · Tailwind · Blender (asset pipeline)

## Run locally
```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```

## Controls
WASD move · Mouse look (click to lock) · Shift sprint · Space jump · E interact · F car · Tab map · M minimap · C camera · Esc pause

## Deploy
Import this repository in Vercel (framework preset: Next.js). No environment variables are needed.
